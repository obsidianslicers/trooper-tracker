# VS Code Extensions

Recommended extensions for PHP and Laravel development.

## Required Extensions

| Extension | Description |
|-----------|-------------|
| `devsense.composer-php-vscode` | Composer integration for PHP Tools — provides autocompletion, dependency insights, and composer.json awareness |
| `devsense.intelli-php-vscode` | IntelliSense for PHP — offers smart code suggestions, parameter hints, and method completions tailored to PHP syntax |
| `devsense.phptools-vscode` | Full-featured PHP development toolkit — includes debugging, code navigation, refactoring, and Laravel support |
| `devsense.profiler-php-vscode` | PHP Profiler — enables performance profiling and bottleneck analysis directly within VS Code |
| `google.geminicodeassist` | Gemini Code Assist — AI-powered code suggestions and completions, useful for rapid prototyping and refactoring |
| `mehedidracula.php-namespace-resolver` | PHP Namespace Resolver — automates `use` statement imports, sorting, and cleanup for cleaner, maintainable code |
| `shufo.vscode-blade-formatter` | Laravle Blade Formatter — an opinionated Blade file formatter for VSCode. |

## VS Code Settings

Project-wide settings are committed in `.vscode/settings.json`.
